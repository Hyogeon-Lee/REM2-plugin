# Source Guides

These files are bundled copies of the user-provided official prompting guides used to design the skill. Load them only when a prompt enhancement requires exact source details beyond the summarized model profiles.

- `gpt-5.5-prompting-guide.md`: outcome-first prompting, retrieval budgets, validation loops, phase handling, formatting, and stopping conditions.
- `gpt-5.6-prompting-guide.md`: GPT-5.6 variants (sol/terra/luna), shorter minimal prompts, autonomy and permission policy, brevity-instruction sensitivity, warmth control, pro mode, programmatic tool calling, multi-agent, and reasoning-effort migration.
- `claude-prompt-best-practice.md`: general Claude prompting guidance, XML structure, examples, long-context prompting, tool use, thinking, and agentic systems.
- `opus-4.8-prompting-guide.md`: Opus 4.8 verbosity, effort calibration, tool triggering, literal instruction following, subagents, frontend defaults, and code review.
- `sonnet-5-prompting-guide.md`: Sonnet 5 effort, adaptive thinking, tool use, literal instruction following, parameter constraints, frontend defaults, and code review.
- `fable-5-prompting-guide.md`: Fable 5 long-horizon work, progress grounding, boundaries, subagents, memory, and reasoning-extraction avoidance.
